# 安全与部署边界

这是单字幕组、自托管的早期版本，尚未经过独立安全审计或生产负载测试。MIT 不提供服务可用性保证。
支持维护范围是当前 0.2.x 服务端；发现问题请使用最新修复版本并先备份。

- 无默认管理员密码、无公开注册；密码使用 Argon2id，登录令牌只保留在网页内存。
- 默认只监听本机。公网必须通过 HTTPS，绝不直接公开 data/backups 或数据库。
- 部署操作和 Docker 权限只交给可信管理员；用户上传内容不能作为命令执行。
- 不把口令、token、视频、字幕或数据库发到公开 issue。若仓库已启用 GitHub 私密漏洞报告，请走 Security → Report a vulnerability；没有私密渠道时先开不含细节的联系请求。
- 备份包含敏感内容，应限制访问并异地保存，定期演练恢复。容器化不等于安全审计。
- 当前没有 MFA、公共注册、跨字幕组多租户、自动依赖安全更新、统一生产监控或分布式数据库。
- 应用按客户端 IP 与账号限速；反向代理下 IP 可能合并，代理层需自行配置可信限流。不要盲目信任任意 X-Forwarded-For。
- 数据卷应放本地可靠文件系统，不共享给多个进程/主机并行写入；禁止多 worker 部署。
- 源码包中的测试口令都是一次性 fixture，不是内置登录账号。安装交互密码会要求确认，自动化环境变量初始化只应在受控流水线使用。
