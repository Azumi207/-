帧语工作台 · 网页服务端 0.2.1
================================

给使用者：解压 Windows 整包，双击「启动工作台.cmd」。
无需安装 Python、Node.js 或数据库，无需联网下载运行依赖。
不要只复制 exe；_internal 文件夹也必须保留。
首次启动按提示设置管理员用户名和至少 12 字符的密码（输入密码时不显示字符），随后自动打开网页。
再次启动不会覆盖账号和项目。保持服务窗口运行，Ctrl+C 停止。
网页默认地址：http://127.0.0.1:8765/

管理员：登录 → 成员管理 → 创建组员 → 新建项目 → 分配项目角色。
片源：上传原片，校验完成后开放初翻任务。
初翻：领取 → 下载片源/最新字幕 → 用帧语或 Aegisub 编辑 → 上传 ASS/SSA → 提交校对。
校对：领取 → 下载检查 → 如有修改先上传草稿 → 填意见退回，或通过。
压制：下载固定的已通过字幕和片源，在 Windows 帧语客户端本地压制。

此版网页是协作工作台，不是浏览器字幕编辑器。不自动执行压制、发布、字体收集或字幕合并。
每个项目每人一个角色；组员仅能访问分配给自己的项目。管理员可以看所有项目。
密码和登录令牌不会写入网页本地存储；刷新页面需重新登录。
字幕须为 UTF-8 ASS/SSA，最多 4 MB。网页片源上限 20 GB，分块续传。
视频上传使用后台增量 SHA-256 校验，不会一次把整个视频读进内存。
Edge/Chrome 在 HTTPS 或本机地址下支持流式保存大视频。
不支持流式保存的浏览器限制在 256 MB；更大文件请使用桌面客户端。
传输被取消时已上传分块保留，可重新选择同一文件续传；移除分块请点“取消未完成上传”。
请勿跨版本直接提交旧字幕。出现冲突时刷新并下载最新版本，手动合并后再提交。

本机启动不等于公开上线！
默认只监听 127.0.0.1，不改防火墙、不开公网端口。其他成员远程使用需部署到服务器并配置域名和 HTTPS 反向代理。
详细部署、配额、安全边界与备份说明见 README.md。禁止把无 HTTPS 的服务直接暴露到公网。
默认 data/ 在 exe 同级目录，保留账号、项目、片源与版本，切勿打包发给不相关人员。
已有 0.1.0 数据可用 --data 指向原 data 目录；先停止旧进程并备份，再启动新版，切勿两个进程同时使用同一数据库。

命令示例（在 exe 所在文件夹终端运行）：
FrameflowServer.exe --port 8766
FrameflowServer.exe --data "D:\FrameflowData"
FrameflowServer.exe --cli --data "D:\FrameflowData" backup "D:\Backup\Frameflow-20261019"
FrameflowServer.exe --cli --data "D:\FrameflowData" reset-password username
FrameflowServer.exe --cli --data "D:\FrameflowData" disable-user username
FrameflowServer.exe --cli --data "D:\FrameflowData" cleanup-uploads
数据锁用于阻止同一数据目录的两个 launcher 同时启动。服务端原 CLI 也必须遵守单进程运行约定。
端口占用会报错，不会悄悄打开其他服务。权限错误时请把整包放入当前用户可写的目录。

给开发者：源码包双击「生成Windows整包.cmd」生成新的独立 Windows 包。
生成机器需要 Python 3.12+ 和联网安装固定依赖；生成后的使用机器不需要 Python 或联网安装依赖。
输出默认为 generated/，已有目录不会覆盖；可用 build-windows.ps1 -Output 新目录 -Python Python完整路径。
源码也可使用 start.cmd / start.sh 启动（需要 Python 3.12+）。Linux 启动脚本未做真机验证。
Windows 包暂未数字签名；不建议关闭系统安全防护，发布给大范围用户前应完成签名与安全审查。

密码确认与恢复（0.2.1）
网页新建成员需输入并确认相同密码，不一致不发送创建请求；服务端收到不一致的确认字段也会拒绝。
忘记或输错密码：在实际服务端机器双击重置密码.cmd，核对数据目录，输入账号名和两次相同新密码。
自定义 data 目录请使用 FrameflowServer.exe --data 完整路径 --reset-password。不会删除账号、项目、片源或字幕。
没有现有数据库时会拒绝，不会给你生成一个空工作台。成功后旧会话失效，重新登录即可。
这是本机运维功能，不是免验证的网页找回入口；普通组员需要联系服务端管理员。
