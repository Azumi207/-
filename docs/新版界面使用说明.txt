帧语 Windows · 圆角工作台（2026-10-20）

这是原 Windows 客户端的新界面，不是网页预览。

1. 完整解压便携包后，双击“启动帧语.cmd”。内置 .NET，不需要用户自行安装。
   媒体组件沿用原安装器与校验机制：首次使用可能联网下载；已有完整 Engine 时复用。
2. 右上角可选择“浅色”“深色”“跟随系统”；视图 → 外观主题也能切换。
   外观选择保存在 %LOCALAPPDATA%\Frameflow\appearance-v1.json。
   该文件独立于旧版显示设置，不写入 ASS，也不修改 Aegisub 配置。
3. 左视频、右波形和编辑、下字幕表的分区不变。小窗口的右侧区域可上下滚动，
   保留完整编辑、样式、校对控件；放大窗口可同时看到更多内容。
4. 原有十个菜单、说话人、共享样式/行内覆盖、ASS/SSA/SRT、校对、团队大厅、
   自动化、GPU 压制和仅音频播放继续使用原有功能。
5. 原快捷键不改：S/空格播放选段，H 停止，E 句首、D 句尾；
   输入框中仍输入文字，Ctrl+P 播放/暂停，Enter 提交下一句，Shift+Enter 换行。
   F11 全屏，Esc 返回；完整说明仍见帮助菜单。
6. 切换主题不会提交当前草稿、清空撤销或重新打开媒体。
7. 旧版源码和便携包另外备份；换回旧版时直接使用旧目录或解压备份包，
   不要把两个版本的文件混合覆盖。字幕与素材不包含在程序备份中，请另行保存。

这次只更新 Windows 客户端界面；没有修改服务端协议或把新版上传到 GitHub。
Windows 的文件选择/消息框仍由系统绘制，外观受 Windows 本身设置影响。
