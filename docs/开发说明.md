# 开发说明

## 客户端

使用 .NET 10 SDK 和 Windows 10/11 x64。源码为 WPF，依赖 MoonSharp 2.0.0（保留其原许可证）。

```powershell
./scripts/install-ffmpeg.ps1 -Destination ./tools/ffmpeg
./scripts/install-native-ass.ps1
dotnet build windows-client/Frameflow.csproj -c Release
dotnet windows-client/bin/Release/net10.0-windows/Frameflow.dll --self-test (Join-Path (Get-Location) "verification/core")
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-client.ps1
```

核心测试生成自己的字幕/音频夹具，不需要用户视频，但包含实际压制检查，因此必须先安装媒体引擎再构建。可见界面/播放性能测试另需桌面；CI 测试不代表全部 GPU/高分辨率显示设备通过。
当前运行时为 .NET 10 LTS，便携包固定为 .NET 10.0.13；按[微软支持周期](https://dotnet.microsoft.com/platform/support/policy/dotnet-core)，支持至 2028-11-14。自包含包不会随系统运行时更新，应定期重建发布。

## 共享服务端

```sh
cd server
python -m venv .venv
# Linux: source .venv/bin/activate；Windows: .venv\Scripts\activate
python -m pip install -r requirements-test.txt
python -m pytest -q
python ci/package.py
```

真实 Docker 验收：在 server 目录 `python ci/docker_smoke.py`。它仅操作随机 frameflow-ci-* 测试项目和卷，结束后清理自己创建的测试资源。
生成 Windows 服务端必须在 Windows 上运行 `server/build-windows.ps1`；PyInstaller 输出独立运行目录及 ZIP，不需要最终使用者安装 Python。
服务端存储 schema 1、API 1，必须保留与客户端 0.2.0 的交互兼容性，不可删库升级。

## 发布检查

根目录 `python scripts/check-repository.py` 检查公开文件白名单、体积和常见令牌特征（不是完整安全审计）。
`python scripts/package-source.py` 生成新的源码 ZIP，已有同名 ZIP 会拒绝覆盖。
新增公开文件须加入 repository-files.json；数据、缓存、安装包不在清单中。依赖和媒体工具版本更新需要重新审核许可证、校验值和回归结果。

## 免 .NET 便携包

构建机器需要 SDK，最终用户不需要。公开包使用 `-WithoutMedia`，即使工作区已有 tools/ffmpeg，也通过 IncludeMediaEngine=false 排除媒体二进制。

```powershell
./scripts/build-client.ps1 -WithoutMedia -Output C:/build/frameflow-portable
python scripts/package-client.py --publish C:/build/frameflow-portable
```

解压 ZIP 后，使用自带安装脚本准备 Engine，再运行 `python scripts/test-portable.py --app 解压后的Frameflow目录 --output 全新测试目录`。该测试临时指向空 DOTNET_ROOT_X64/ROOT、移除 dotnet PATH，并记录 apphost 的本地 CLR 加载路径；不卸载或改变系统 .NET。真实无 SDK 的干净 Windows 虚拟机验收仍建议在每次正式发布前执行。
