# GitHub 发布说明

目标仓库：https://github.com/Azumi207/-

## 源码与安装包分开

Git 仓库提交 repository-files.json 白名单里的源码/文档/脚本，不提交 release-assets、bin、obj、data、backups、.env、视频、数据库和临时凭据。
本地 release-assets 目录包含整理好的三种平台安装包以及源码 ZIP，应上传至 GitHub Releases，而不是硬塞进源码提交。
[GitHub 文件限制与 Releases 说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。

首次源代码提交前运行 `python scripts/check-repository.py`，核对 git diff --cached。不要把整个原开发工作区上传。
本地生成的包不等于已经上传；以真实 push/Release 的返回结果为准。脚本不会强推或覆盖别人提交。

## 版本

- 客户端 0.2.0 Portable：内置 Windows x64 .NET 10.0.13，无需用户安装运行时；保留编辑器功能。ZIP 不包含独立 GPL FFmpeg，首次通过上游下载并固定校验。旧轻量 ZIP 保留在历史 Release，不建议新用户选择。
- 服务端 0.2.2：Linux/Windows 共用源码，Windows ZIP 根据 VERSION 命名并携带依赖许可证。
- 可使用一个项目 Release 描述这些组件版本，不必假装它们版本号一致。
