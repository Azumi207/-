# 帧语使用说明

## 选哪个程序？

| 程序 | 给谁用 | 作用 |
|---|---|---|
| Windows 客户端 | 初翻、打轴、校对、压制 | 本地做字幕、调整样式、导出带字幕视频 |
| Linux 服务端 | 字幕组管理员 | 长期部署网页、保存项目和交接版本 |
| Windows 服务端 | 字幕组管理员 | Windows 上快速试用/自建同一网页工作台 |

服务端两种版本任选一种，不必都部署。组员使用浏览器或客户端连接，不需要每个人安装服务器。

## 个人做字幕

1. 完整解压客户端 ZIP，安装 .NET 9 Desktop Runtime x64，双击 start-client.cmd。首次会下载并验证独立媒体组件。
2. “文件”中打开视频和 ASS/SSA 字幕，或新建字幕。编辑前保留原文件；导入有警告时先核对。
3. 波形区选择起止时间，字幕区输入初翻。按键受焦点影响，文本输入时不要把普通字母误当打轴快捷键。
4. 可开启“仅音频”专注听打；视频区域悬停显示十字与坐标。
5. 在字幕列表设置说话人、样式，在视频预览中调整位置。高级 ASS 标签尽量保留；冲突时按提示处理。
6. 切换校对模式，定位疑似闪轴、过短显示等问题。检测是提示，不等于每条都应自动修改。
7. 用保存/另存为保留 ASS；导出其他格式可能损失样式，确认输出格式。
8. 选择“压制字幕到视频”，先预览短片，再正式输出。自动尝试可用显卡编码，失败回退 CPU。解码/字幕绘制不保证全部 GPU 加速。

字体必须在压制机器可用；不保证预览与复杂 ASS 最终渲染逐像素一致。原视频和已有输出不会被默默覆盖。

## 管理员准备工作台

Linux：安装 Docker Engine 和 Compose 后执行 `sh linux-server/install.sh`。
Windows：解压服务端独立包，双击 `启动工作台.cmd`。
首次输入管理员用户名、密码、确认密码；无默认密码。默认仅服务器本机 http://127.0.0.1:8765 。
在服务器验证后配置 HTTPS 与域名，将 HTTPS 地址发给组员。不要直接向公网暴露明文登录或数据目录。

登录网页 → 成员管理创建账号 → 新建项目 → 分配 source / translator / reviewer / encoder 角色。
成员只能访问获准项目。一个成员在同一项目中只有一种角色，管理员可代办，但不能通过自己提交的初翻。

## 字幕组交接

1. **片源**上传视频。分块上传支持中断续传；完成后验证 SHA256，片源固定，换片源应建新项目。
2. **初翻**领取任务，下载视频和字幕工作副本，在客户端打轴/翻译。离线仍可编辑。
3. 保存后提交草稿或“完成初翻、交给校对”。不要删除关联 sidecar 或盲目覆盖其他人的版本。
4. **校对**领取、下载最新副本，修改后上传。退回需填写原因；初翻重新领取后修订。
5. **校对通过**固定具体字幕版本，进入待压制。**压制**下载通过版本与片源，本地输出成片。

网页不直接编辑字幕、不自动压制、不自动发布。额外字体、素材和逐行校对 sidecar 暂需另行交接。
冲突时服务器拒绝覆盖，先保存自己的离线副本，下载最新版本人工比较合并。没有多人实时合写和自动合并。
大视频下载推荐支持流式保存的浏览器，在 HTTPS 或 localhost 下使用；否则优先 Windows 客户端。

## 密码、备份与停止

- 忘记密码：联系服务器管理员，在主机本地重置；不会通过公共网页跳过身份验证。
- Linux：`sh linux-server/manage.sh reset-password admin`，输入两遍新密码；`backup` 生成一致性快照。
- Windows：`重置密码.cmd`；备份用 `FrameflowServer.exe --cli --data 数据目录 backup 新备份目录`。
- 备份完成标记为 BACKUP_COMPLETE.txt，包含私有账户/视频，应限制访问并异地保存。
- 停止服务不删数据；禁止随意运行 docker compose down -v。
- 迁移/恢复先用新空目录或新卷验证，不覆盖正在运行的数据库。

更多运维细节见 [Linux 指南](../server/docs/LINUX.md)。
