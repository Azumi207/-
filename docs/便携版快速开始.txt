帧语 Windows 免安装便携版（64 位）

1. 下载名称带 Portable-win-x64 的 ZIP。
2. 右键 ZIP → 全部解压，选择桌面或其他你有写入权限的文件夹。
3. 打开解压后的 Frameflow 文件夹，双击「启动帧语.cmd」。
4. 第一次会自动下载媒体组件，等待窗口完成后就会打开软件。

不需要安装 .NET、Python 或开发工具，不需要管理员权限。
「启动帧语.cmd」与 start-client.cmd 是相同入口。
首次准备媒体组件需要联网；成功后再次启动可离线使用本地编辑功能。
不要在压缩包里直接运行，也不要只复制 Frameflow.exe；请保留整个文件夹。
离线电脑请先在联网电脑完成一次启动，再复制整个文件夹（个人使用）。

打不开怎么办？
- 需要 Windows 10/11 x64；不支持 Windows 7、32 位 Windows。
- 出现缺文件提示：重新完整解压，不必安装 .NET。
- 下载失败：检查网络，换到桌面等可写目录，再双击启动。
- 校验失败：请下载项目更新版本，不能绕过安全校验。
- 本包尚未数字签名，Windows 可能提示未知发布者。仅从项目官方 Releases
  下载并核对 SHA256；不建议关闭系统防护。

更新：把新版本解压到新文件夹，保留旧版和字幕备份，再打开自己的字幕。
不要用覆盖旧目录的方式升级运行时；本包不会替你安装系统组件或改注册表。
卸载：关闭软件后，自行删除程序文件夹。请不要误删自己的字幕、视频和项目。
