帧语 · 波形低延迟与首尾精修

一、使用
1. 打开视频或音频，选择一句字幕。原有 S/H/D/E、Ctrl+3/4、F8/F9 不变。
2. 展开波形下方“首尾精修 · 放大 / 试听 / 微调”。小窗口可滚动右侧编辑区。
3. 选起点或终点，局部视窗可选 0.5 / 1 / 2 秒，不改变主波形缩放。
4. 点“听边界前后”：边界前后各 200 / 300 / 500 ms；点“听实际选区”：只播放字幕实际起止范围。
5. 勾选“循环”可反复听。点 ±10 / 50 / 100 毫秒微调；正在试听时会重听调整后的范围。
6. 局部波形拖动只改当前选中的起点或终点。每次拖动/微调可撤销。
7. H / 停止结束试听；切换字幕、收起精修或切换播放模式也会停止旧试听。未增加自动吸附。

二、拖动改动
主波形与边界线分层绘制，不因边界每次移动重绘整张波形。
拖动时字幕时间为临时草稿，松手或失去鼠标捕获后一次提交；撤销恢复整次拖动。
视频定位最多每 100ms 取最新位置，ASS 使用已有的常驻 libass 缓存，忙时不排队、不反复清空画面。
松手后以精确预览管线校准最终时间。关闭“联动”后拖动不会跳转播放器。

三、限制
ASS 存储精度 10ms。微调与保存使用同一精度；没有宣称采样级定位或逐帧 VFR 定位。
试听使用原有 Windows 媒体播放时钟及范围停止检查，设备缓冲可能有少量尾音延迟，不是采样级无缝音频循环。
播放范围截在媒体长度内；字幕时间允许超出媒体以便离线编辑。
自动语音边界、自动吸附及新增微调快捷键的自定义界面暂未实现；既有键位保持原样。
测试使用实际 WPF 回调、媒体时钟与静音夹具，并非人耳监听或鼠标到屏幕的端到端延迟测量。
